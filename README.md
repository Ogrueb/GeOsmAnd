# GeOsmAnd

Geology maps for [OsmAnd](https://osmand.net): bedrock units, faults, mines, fossils and
strike/dip measurements packed as offline OsmAnd map files.

**Status: early testing.** For now this repository only hosts test builds
(see [Releases](https://github.com/Ogrueb/GeOsmAnd/releases)). Every release here is a
pre-release test build, not a finished map. Expect changes, rough edges and breaking
updates between rounds.

Only regions whose source-data licences have been checked are published. At the moment
that is Colorado (U.S. Geological Survey and National Park Service sources). Attribution
for each build ships inside its release.
